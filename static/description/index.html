🎯 Subscription Plans Module

Comprehensive subscription management with three tiers: Try Out, Free, and Premium

✨ Key Features

  • Three subscription tiers with different access levels
  • Beautiful, modern frontend interface
  • Simulated payment processing
  • User subscription tracking and management
  • Admin backend for plan configuration
  • Responsive design for all devices

👁️ Try Out

No registration required. Limited access to try-out decks only.

👤 Free (Popular)

Registration required. Create up to 3 private decks with 54 cards each.

👑 Premium

Full access with unlimited decks, AI features, and premium content.

🚀 Getting Started

  1. Install the module
  2. Visit /subscription/plans to see the plans page
  3. Configure plans in the backend under Subscriptions menu
  4. Users can select plans and get subscriptions
